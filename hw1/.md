# 2^n 演算法效能與遞迴觀念測試報告

本實驗實作並測試四種計算 $2^n$ 的方法，觀察不同演算法的時間複雜度差異，並測試 $n = 100$ 時的執行狀況。

---

## 程式碼實作

```python
import time

# --- 方法 1：內建運算子 (極速) ---
def power2n_1(n):
    return 2**n

# --- 方法 2a：純遞迴 (指數成長，會出不來) ---
def power2n_2a(n):
    if n == 0:
        return 1
    return power2n_2a(n-1) + power2n_2a(n-1)

# --- 方法 2b：線性遞迴 (每次乘 2) ---
def power2n_2b(n):
    if n == 0:
        return 1
    return 2 * power2n_2b(n-1)

# --- 方法 3：遞迴 + 查表 (Memoization) ---
memo = {0: 1}
def power2n_3(n):
    if n in memo:
        return memo[n]
    memo[n] = power2n_3(n-1) + power2n_3(n-1)
    return memo[n]

# --- 主程式測試 ---
if __name__ == "__main__":
    n = 100
    
    print(f"=== 測試 n = {n} ===")
    
    # 1. 測試方法 1
    start = time.perf_counter()
    res1 = power2n_1(n)
    end = time.perf_counter()
    print(f"方法 1 (2**n)       : 耗時 = {(end - start)*1000:.6f} ms")
    
    # 2. 測試方法 2b
    start = time.perf_counter()
    res2b = power2n_2b(n)
    end = time.perf_counter()
    print(f"方法 2b (線性遞迴)  : 耗時 = {(end - start)*1000:.6f} ms")
    
    # 3. 測試方法 3
    start = time.perf_counter()
    res3 = power2n_3(n)
    end = time.perf_counter()
    print(f"方法 3 (遞迴+查表)  : 耗時 = {(end - start)*1000:.6f} ms")
    
    # 4. 關於方法 2a 的特別說明
    print("\n--- 關於方法 2a 的狀況 ---")
    print("方法 2a (`power2n_2a(100)`) 時間複雜度為 O(2^n)。")
    print("如果硬跑 n = 100，總共需要進行約 1.26 × 10^30 次計算，程式會直接卡死「出不來」。")
