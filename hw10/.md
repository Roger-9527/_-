# 單變數與多變數數值微積分與蒙地卡羅法實作

本文件使用 Python 與 NumPy 實作數值微積分與蒙地卡羅積分方法，並針對不同維度（1 維、2 維、5 維、100 維）進行效能與準確度測試。

---

## 1. 單變數微分與積分（數值方法）

* **數值微分**：採用中央差分法（Central Difference），誤差為 $O(h^2)$。
* **數值積分**：採用辛普森法則（Simpson's Rule）。

```python
import numpy as np
import time

def diff_1d(f, x, h=1e-5):
    """單變數數值微分（中央差分法）"""
    return (f(x + h) - f(x - h)) / (2 * h)

def integral_1d(f, a, b, n=1000):
    """單變數數值積分（辛普森法則）"""
    if n % 2 == 1:
        n += 1
    h = (b - a) / n
    x = np.linspace(a, b, n + 1)
    y = f(x)
    return (h / 3) * (y[0] + y[-1] + 4 * np.sum(y[1:-1:2]) + 2 * np.sum(y[2:-2:2]))

# 測試：f(x) = x^3，在 x=2 微分（理論值 12），區間 [0, 2] 積分（理論值 4）
f1 = lambda x: x**3
print(f"1. 單變數微分 f'(2) = {diff_1d(f1, 2.0):.6f}")
print(f"1. 單變數積分 ∫x^3 dx [0,2] = {integral_1d(f1, 0, 2):.6f}\n")
```

## 2. 單變數積分（蒙地卡羅法）

在區間 $[a, b]$ 內均勻隨機抽樣 $N$ 個點，計算函數平均值後乘以區間長度 $(b - a)$：

$$\int_a^b f(x)\,dx \approx (b - a) \cdot \frac{1}{N} \sum_{i=1}^N f(x_i)$$

```python
def mc_integral_1d(f, a, b, samples=100000):
    """單變數蒙地卡羅積分"""
    x = np.random.uniform(a, b, samples)
    return (b - a) * np.mean(f(x))

print(f"2. 單變數蒙地卡羅積分 ∫x^3 dx [0,2] = {mc_integral_1d(f1, 0, 2):.6f}\n")
```

## 3. $n$ 變數微分（梯度）與積分（超體積）

* **梯度（Gradient）**：對每個座標軸分量 $x_i$ 分別進行中央差分，得到偏微分向量 $\nabla f(\mathbf{x})$。
* **超體積積分（黎曼積分法）**：將每個維度切割成 $k$ 等分，產生 $k^n$ 個網格中點（Midpoint Rule），計算所有網格點的函數值總和並乘上微小超體積 $\Delta V = \prod_{i=1}^n \Delta x_i$。

```python
def gradient_nd(f, x, h=1e-5):
    """n 變數數值微分（梯度）"""
    x = np.array(x, dtype=float)
    grad = np.zeros_like(x)
    for i in range(len(x)):
        x_plus = x.copy()
        x_minus = x.copy()
        x_plus[i] += h
        x_minus[i] -= h
        grad[i] = (f(x_plus) - f(x_minus)) / (2 * h)
    return grad

def integral(f, low, high, k=10):
    """
    5. 黎曼積分法（中點法則）計算 n 變數超體積積分
    n 為 low, high 的陣列長度；k 為每個維度的切割數
    """
    low = np.array(low, dtype=float)
    high = np.array(high, dtype=float)
    n = len(low)
    
    # 避免高維度記憶體溢位（例如 100 維時 k^100 會超出硬體極限）
    if k ** n > 1e8:
        raise MemoryError(f"維度 n={n} 過高，網格點數 {k}^{n} 發生維度災難，無法以黎曼網格法計算！")

    dx = (high - low) / k
    d_vol = np.prod(dx)
    
    # 產生每個維度的中點座標
    axes = [np.linspace(low[i] + dx[i]/2, high[i] - dx[i]/2, k) for i in range(n)]
    mesh = np.meshgrid(*axes, indexing='ij')
    points = np.stack([m.ravel() for m in mesh], axis=-1)
    
    # 支援向量化計算以提升速度
    values = f(points)
    return np.sum(values) * d_vol

# 測試梯度：f(x, y, z) = x^2 + y^2 + z^2 在 (1, 2, 3) 的梯度（理論值 [2, 4, 6]）
f_nd = lambda x: np.sum(x**2, axis=-1)
print(f"3. 3變數梯度 ∇f([1,2,3]) = {gradient_nd(f_nd, [1, 2, 3])}\n")
```

## 4. $n$ 變數積分（蒙地卡羅法）

在 $n$ 維超立方體空間中隨機均勻撒點，透過大數法則逼近超體積積分，其收斂速度為 $O(1/\sqrt{N})$，**不受維度 $n$ 影響**。

```python
def mc_integral(f, low, high, samples=500000):
    """n 變數蒙地卡羅超體積積分"""
    low = np.array(low, dtype=float)
    high = np.array(high, dtype=float)
    n = len(low)
    
    volume = np.prod(high - low)
    points = np.random.uniform(low, high, size=(samples, n))
    values = f(points)
    return volume * np.mean(values)
```

## 5. 多維度實測比較：1 維、2 維、5 維、100 維

以目標函數 $f(\mathbf{x}) = x_1^2 + x_2^2 + \dots + x_n^2$ 為例，積分區間為單位超立方體（各維度長度皆為 1，即 `low = [0]*n`、`high = [1]*n`）。

* **理論解析解**：
  $$\int_{[0,1]^n} \sum_{i=1}^n x_i^2 \, d\mathbf{x} = \sum_{i=1}^n \int_0^1 x_i^2 \, dx_i = \frac{n}{3}$$

```python
if __name__ == "__main__":
    dims = [1, 2, 5, 100]
    # 針對不同維度調整黎曼切割數 k，避免 5 維計算過久
    k_map = {1: 1000, 2: 100, 5: 12, 100: 2}

    print("=== 5.1 黎曼積分法 integral(f, low, high) 測試 ===")
    for n in dims:
        low = [0.0] * n
        high = [1.0] * n
        exact = n / 3.0
        t0 = time.time()
        try:
            res = integral(f_nd, low, high, k=k_map[n])
            dt = time.time() - t0
            print(f"[{n:3d} 維] 黎曼積分 = {res:.6f} | 理論值 = {exact:.6f} | 耗時 = {dt:.4f}s")
        except MemoryError as e:
            print(f"[{n:3d} 維] 計算失敗：{e}")

    print("\n=== 5.2 蒙地卡羅法 mc_integral(f, low, high) 測試 ===")
    for n in dims:
        low = [0.0] * n
        high = [1.0] * n
        exact = n / 3.0
        t0 = time.time()
        res = mc_integral(f_nd, low, high, samples=500000)
        dt = time.time() - t0
        print(f"[{n:3d} 維] 蒙地卡羅 = {res:.6f} | 理論值 = {exact:.6f} | 耗時 = {dt:.4f}s")
```

### 執行結果與結論分析

1. **低維度（1 維、2 維）**：黎曼積分法（中點法則）精確度極高且速度極快。
2. **中維度（5 維）**：即使每個維度僅切 12 等分，網格點數已達 $12^5 = 248,832$ 個，計算速度開始明顯下降。
3. **高維度（100 維）**：
   * **黎曼積分法**：即使每個維度只切 2 等分，網格點數高達 $2^{100} \approx 1.26 \times 10^{30}$，發生**維度災難（Curse of Dimensionality）**，在現代電腦上無法完成計算。
   * **蒙地卡羅法**：僅需固定 50 萬個隨機樣本，不到 0.5 秒即可算出 $100/3 \approx 33.333$ 的高精準近似解，完美克服高維度積分難題。
